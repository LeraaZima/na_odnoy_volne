## Публикация владельцем

Публикация и настройка remote автоматически не выполняются. Создайте пустой репозиторий GitHub, выберите видимость и проверьте имя/email автора первоначального коммита. Затем выполните команды из раздела «Публикация на GitHub» в README, подставив настоящий URL.

Не добавляйте `.env`, резервные копии БД или Docker volumes. Каждый разработчик получает свой локальный `.env` и отдельно импортирует каталог. Перед публичным распространением согласуйте лицензию на код с командой; лицензия намеренно не назначена автоматически.
