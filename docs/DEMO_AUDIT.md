# Аудит демонстрационной версии — 6 ноября 2026

> Последующая подготовка к GitHub проверила чистый том, добавила lock-файлы и подтвердила работу Git вне песочницы. Актуальные результаты — в [GITHUB_PREPARATION.md](GITHUB_PREPARATION.md). Ниже сохранён отчёт предыдущего этапа.

## Итог

Версия подходит для локальной университетской демонстрации на проверенном компьютере с Docker и подготовленным каталогом. Основной сценарий проверен в двух независимых процессах Google Chrome, с настоящими HTTP-запросами, PostgreSQL и Socket.IO. Рабочие компоненты не переписывались, новые продуктовые функции и SQL-миграции не добавлялись.

## Найдено и исправлено

1. **Комната, истёкшая во время отключения сети, оставалась на экране.** Браузерный тест воспроизвёл проблему: после возвращения сети кнопка создания комнаты не появлялась. Теперь при восстановлении сети и ошибке подключения Socket.IO выполняется HTTP-проверка сессии. Подтверждённый отказ в доступе очищает локальную сессию, временная сетевая ошибка — нет. При разрыве подключения показывается сообщение о восстановлении.
2. **Неполные правила исключения окружения.** Варианты вроде `.env.local` не покрывались прежним шаблоном. Теперь `.env` и `.env.*` исключены из Git и контекстов обоих Docker-образов, кроме `.env.example`.
3. **Повторяющиеся идентификаторы описаний.** Один фильм в историях разных подборок получал одинаковый HTML ID. Теперь React выдаёт уникальный ID каждому экземпляру карточки, чтобы кнопки раскрытия корректно связывались со своим текстом для вспомогательных технологий.

## Проверка секретов

Значение настроенного TMDB-секрета не выводилось. Поиск его точного значения не обнаружил совпадений в текущих исходниках, клиентской сборке и доступных логах Docker. Проверены также 63 распакованных Git-объекта: совпадений нет, pack-файлов нет. Это проверка имеющегося локального содержимого, не аудит удалённых репозиториев, внешних резервных копий или ранее опубликованных материалов.

Системный `git status` недоступен из-за отсутствующих macOS Command Line Tools; проверка локальных Git-объектов выполнена непосредственно через Node.js. Токен передаётся только backend, клиент не получает TMDB-переменные окружения. Ошибки TMDB-клиента не выводят URL с API Key.

## Оставшиеся ограничения

- Не проверялись реальные iPhone/Android и Safari/Firefox; мобильная проверка — Chrome с viewport 390 px и touch-событиями.
- Не проверялось развёртывание с совершенно пустым томом на другом компьютере. Для защиты используйте подготовленный локальный Docker; не удаляйте его данные.
- Зависимости пока задаются диапазонами без сохранённых lock-файлов. Сборка с нуля в будущем может получить другие версии; текущие собранные образы проверены.
- Без сети постеры могут заменяться заглушками. Пять фильмов исходного каталога не имеют описания.
- Нет отмены оценки и передачи прав создателя. После его выхода готовая подборка остаётся доступна, новые настройки требуют новой комнаты.
- Нет автоматической очистки истёкших комнат и долговременной очереди уведомлений. Пропущенный Match сохраняется в БД и восстанавливается в истории, но праздничная анимация задним числом не проигрывается.
- Не проводились нагрузочный тест и полноценный аудит безопасности для публичного размещения. Это локальный учебный MVP.

Перед записью достаточно проверить healthcheck, открыть два независимых браузера и создать свежую комнату. Инструкции запуска и повторения тестов — в [README](../README.md).
