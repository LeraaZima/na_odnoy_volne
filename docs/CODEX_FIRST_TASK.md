# Первая задача для Codex

Сначала открой корневую папку проекта в Codex и вставь этот текст:

> Ты помогаешь нам делать MVP «На одной волне» для курса «Стартап-экосистемы». Сначала прочитай README.md, AGENTS.md, docs/MVP.md и изучи уже существующий код. **Не переписывай проект с нуля.** Наш первый шаг — проверить Docker Compose, создание комнаты, присоединение второго участника и Socket.IO-синхронизацию. Запусти `docker compose up --build` (если Docker доступен), `cd backend && npm test`, `cd frontend && npm run build`. Если найдёшь ошибки, исправь их минимально. Не добавляй фильтры и свайпы в этой задаче. В конце перечисли изменённые файлы, какие команды реально выполнены, какие проверки прошли и что нужно сделать вручную для проверки в двух окнах браузера.

## Следующая задача после успешного запуска

> Сделай «фильтры и каталог» на основе существующего репозитория. Не меняй текущее API комнат. Добавь миграцию для фильмов и общих фильтров комнаты, 12–20 реалистичных демонстрационных фильмов (без сторонних постеров), API для загрузки списка по выбранным параметрам и мобильный UI фильтров. Поддержи светлую/тёмную тему. Напиши тесты, обнови README и не заявляй о реализованном Match — он будет отдельной задачей.

## Что присылать в ChatGPT для проверки

- Консольный вывод `docker compose up --build` или проблемный фрагмент.
- Отчёт Codex о файлах и проверках.
- Скриншот двух браузерных окон, если интерфейс нужно скорректировать.
