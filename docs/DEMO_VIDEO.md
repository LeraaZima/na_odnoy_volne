# Видео для защиты — около 2 минут

## Подготовка вне записи

- Запустить Docker Compose, проверить healthcheck. Каталог уже должен содержать фильмы.
- Открыть два независимых браузера рядом, подобрать масштаб, чтобы были видны карточки и кнопки. Использовать короткие имена «Лера» и «Антон».
- Начать с главных страниц, выйти из старых комнат. Проверить загрузку постеров и отсутствие уведомлений рабочего стола.
- Сделать пробный проход с фильтрами «год от 2000, рейтинг от 6»: должно оставаться несколько фильмов. На записи создать новую комнату.
- Не показывать `.env`, токены, терминал с окружением или панели Network/Storage.

## Сценарий с таймингом

| Время | Реальные действия | Короткий комментарий голосом |
| --- | --- | --- |
| 0:00–0:12 | Главная, ввод имени, создание комнаты в A | «На одной волне помогает двум людям выбрать кино без долгих споров». |
| 0:12–0:28 | В B другое имя и код; оба окна показывают участников | «Вход без регистрации. Комната рассчитана на двоих и действует сутки». |
| 0:28–0:48 | Открыть фильтры в обоих окнах. A задаёт год и рейтинг, сохраняет; B видит изменения | «Создатель настраивает общую подборку. Настройки сразу видны второму участнику». |
| 0:48–1:03 | A начинает выбор. Показать одинаковый первый фильм и раскрыть описание | «Каталог получен из TMDB. Мы видим одинаковые фильмы в одинаковом порядке». |
| 1:03–1:20 | A свайпает первый вправо, второй влево. B остаётся на первом | «Каждый выбирает в своём темпе. Оценки сохраняются на сервере». |
| 1:20–1:35 | B ставит первому фильму лайк. Оставить Match на обоих экранах на несколько секунд | «Два лайка — совпадение. Вы на одной волне!» |
| 1:35–1:48 | В обоих окнах «Продолжить выбор», открыть историю и подробности | «Можно продолжать искать, а общий список совпадений остаётся доступен». |
| 1:48–2:00 | Обновить страницу, показать сохранённую историю; при наличии времени переключить тему | «Прогресс не теряется после обновления. MVP готов для совместного выбора фильма». |

Записывать настоящие нажатия и реальные ответы приложения. Не подменять Match монтажом. Допустимо убрать только паузы ввода, сохранив последовательность событий. Если постер недоступен, использовать штатную заглушку и не выдавать её за загруженное изображение.

При сбое остановить дубль, проверить Docker и повторить в новой комнате. В финале не обещать просмотр фильма внутри приложения: MVP помогает выбрать, а не воспроизводит видео.
