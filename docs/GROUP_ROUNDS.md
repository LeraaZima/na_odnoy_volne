# Групповые раунды: реализация и проверка

## Правила

Комната вмещает до `ROOM_MAX_PARTICIPANTS` человек (2–10, по умолчанию 10). Пока собирается компания, в комнате может быть один человек; старт требует минимум двух.

При старте сохраняются UUID раунда, упорядоченные карточки, ID и имена всех текущих участников. Только эти участники могут оценивать фильмы. После каждого нового лайка сервер считает лайки за этот фильм среди фиксированного состава. Match появляется при равенстве числа лайков размеру состава, минимум два. Ни отсутствие соединения, ни поздний вход не уменьшают требуемое число голосов.

Голос, проверка совпадения и запись Match выполняются одной транзакцией с блокировкой комнаты. Вход, выход, смена фильтров и новый раунд используют ту же блокировку. Уникальные ограничения голосов и Match сохранены. Идентичный повтор возвращает прежний результат без второй записи; новый раунд использует проверку `revision`, поэтому повтор устаревшего запроса не создаёт ещё один раунд.

Добровольный выход участника текущего раунда помечает его остановленным. Новые оценки запрещены; уже созданные совпадения и голоса остаются. Выход ожидающего гостя не останавливает раунд. Для другого состава ведущий запускает новый раунд. При его выходе выбирается следующий оставшийся онлайн-участник, а если таких нет — следующий оставшийся по времени входа. У пустой комнаты нет ведущего; первый новый гость получает права, если срок комнаты не истёк.

## Подключения и визуальный стиль

Каждый Socket.IO-сеанс имеет запись PostgreSQL с временем истечения. Heartbeat обновляется каждые 20 секунд; запись действует 60 секунд. Выход из вкладки удаляет её подключение, другие вкладки того же гостя продолжают учитываться. Статус может запаздывать при внезапном отключении, но состав раунда от него не зависит. Socket.IO уведомляет о статусах, новом состоянии комнаты и Match.

Авторский SVG состоит из заднего потока, тела с гребнем, переднего потока, бликов и маленьких глаз. Используются полупрозрачные фиолетово-голубые слои. На главной — плавное покачивание, на Match — появление, изгиб и расходящиеся кольца. При reduced-motion движение отключается. Старый PNG сохранён в исходниках как прежний ресурс, но больше не импортируется и не попадает в клиентскую сборку.

## Ограничения и реальные устройства

Проверка LAN выполнена с браузеров на Mac через его сетевой IP; физический телефон и другой ноутбук не были доступны. Это подтверждает маршрутизацию приложения по LAN-origin, но не проверяет настройки firewall/изоляции конкретного телефона. Safari/iOS требуют отдельного прогона.

Удалённый HTTPS-доступ не открывался. В README предложен Cloudflare Tunnel с Access по списку email; настройка требует согласования. PostgreSQL и прямой API остаются на loopback, порт роутера не открывался, `allowedHosts: true` не используется. Backend пока работает одним экземпляром; отказоустойчивый кластер и production-публикация не входят в этот этап.

GitHub не публиковался. Изменения оставлены в рабочем дереве без нового коммита.
